# 手动连接与验收清单

真实 LLM Key、微信扫码登录和外部消息在用户配置完成前保持关闭。本清单用于接通后逐项检查。

## 模型与微信

- [ ] 在 AstrBot WebUI 添加 DeepSeek（或其他支持函数调用的提供商），配置模型并发起一轮普通对话。
- [ ] 按[联网搜索配置](web-search.md)启用 AstrBot Web Search；分别询问近期新闻和已配置地点天气，确认触发工具、标注“联网查询”并带可打开的来源链接。
- [ ] 询问今天的天气，确认走项目 `weather_today` 工具并显示 Open-Meteo 预报来源；再断开外网，确认服务说明暂时无法查询而不编造天气。
- [ ] 分别启用本地“个人助手 Todo”“个人助手课表与日程”“个人助手提醒与复盘”“个人助手推送”插件，确认工具出现在对应人格的函数工具列表。
- [ ] 连接“个人微信”适配器，扫码并确认登录；手机端满足 AstrBot 当前官方要求。
- [ ] 微信发一条问候语，确认收到模型回复。

## Todo 与网页

- [ ] 用微信自然语言创建无截止日期 Todo，检查网页出现同一记录。
- [ ] 用网页修改任务名称、分类、优先级和截止日期，再用微信查询确认更新。
- [ ] 用微信完成任务，检查网页状态；再分别验证搜索、今天任务、即将到期、逾期筛选。
- [ ] 创建每周重复 Todo，选择星期、结束日期和多个提醒时刻；确认近期每期分别出现在列表中。
- [ ] 修改一条重复任务时，分别选择只修改本期和修改整个系列；删除时确认只取消本期或未来整组。
- [ ] 创建父任务和子任务；尝试在子任务未完成时完成父任务，确认系统拒绝，完成子任务后父任务可完成。
- [ ] 发出对象含糊的编辑或删除请求，确认机器人先追问而不是猜任务。
- [ ] 使用管理页删除一项任务，确认需要显式确认；记录仍可在审计日志和数据导出中查看。

## 提醒

- [ ] 创建精确到日期与时刻的提醒，检查提醒队列出现待发送状态。
- [ ] 创建“晚上提醒”这类缺少具体时刻的表达，确认机器人先问清楚。
- [ ] 配置 AstrBot OpenAPI Key，仅授予 `im` scope，并填入项目 `.env` 的 `ASTRBOT_API_KEY`。
- [ ] 确认提醒主动到达绑定的微信会话；服务重启后未到期提醒仍保留。
- [ ] 手动验证失败/结果不确定状态与“确认重试”提示，避免自动重复发送。
- [ ] 开启每日早报与周复盘提醒，检查网页设置可更改时间和开关。
- [ ] 调用“预览今日早报”工具确认其与定时推送内容一致；配置天气坐标/RSS 后核对可选栏目。
- [ ] 在日程页创建单次及每周个人安排，验证与课程/其他安排冲突时仍可保存并显示提示。
- [ ] 开启一门课程的课前提醒并设置提前分钟数，检查到期通知内容和课程时间。
- [ ] 用微信查看周复盘，保存本周总结，并分别创建下周 Todo 与带节次的个人日程。

## 课表、导出和迁移

- [ ] 预览并导入你的 `.xlsx` 工作簿，核对课程、地点、教师、周次和解析错误。
- [ ] 用自己课表中的日期检查教学周计算、星期和课程数是否正确。
- [ ] 验证 14 节课程时间、周视图/日视图及周次前后切换。
- [ ] 查询今天、明天、指定星期和特定课程地点；结果与 Excel 核对。
- [ ] 下载 JSON 与 CSV，确认数据可读且不含密钥。
- [ ] 创建 SQLite 备份并恢复到临时数据库/目标实例，确认数据记录完整。
- [ ] 按迁移文档在另一环境恢复数据库和 AstrBot 数据目录。
